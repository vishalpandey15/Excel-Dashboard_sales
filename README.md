# This project is an interactive Excel dashboard designed to track and analyze sales performance
## across different cities and sales executives. It provides insights into total sales, target
achievements, and performance gaps using charts, tables, and KPIs.

## Dataset

<a href ="https://github.com/vishalpandey15/Excel-Dashboard_sales/blob/main/Dashboard%20excel%20Sales%20Mann.xlsm"> Dataset</a>
■ Features
- City-Wise Sales Tracking: Dashboard tabs for multiple cities (Chennai, Delhi, Mumbai, Nagpur,
Patna, Pune, Ranchi, Surat).
- Sales Executive Performance: Compare total sales among team members.
- Target Hit %: Monitor how close each executive is to achieving their targets.
- Away from Target %: Identify performance gaps for improvement.
- Interactive Charts: Includes bar charts, pie charts, and line graphs.
- Dynamic Dashboards: Filter-based views (Dashboard 1 to Dashboard 4).

The dashboard provides:

Quick insights into total sales, target achievements, and performance gaps.
Dynamic views using filters and buttons to navigate across dashboards.
Data visualization through bar charts, pie charts, and line graphs for easy interpretation.
Comparative analysis of sales executives to identify top performers and those needing improvement.
It is designed for sales teams, managers, and business analysts to make data-driven decisions efficiently.
